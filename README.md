# 📊 Superstore Analytics & Profit Optimization

## 📌 Executive Overview
This repository contains an end-to-end data analytics project evaluating order-level transaction performance for **Superstore Operations**. The core objective is to identify primary profitability drivers, evaluate revenue decay resulting from unmonitored discounting strategies, perform customer RFM segmentation, and provide actionable strategic recommendations to maximize net margins.
